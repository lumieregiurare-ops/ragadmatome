主人公と冒険の仲間

主人公（プレイヤー）ノービス

アースガルドから呼び出された冒険者。いろいろな職業に転職して強くなる。

ソードマンブレイド

記憶をなくした剣士。力強い攻撃が持ち味。

マジシャンスヴァナ

知識が豊富で、落ち着いて魔法を使う。

アーチャーユール

フェイヨン出身のベテラン探検家。

シーフハーディン

仲間思いのムードメーカー。素早い攻撃が得意。

アコライトアイ

回復役。優しいが少し毒舌。
